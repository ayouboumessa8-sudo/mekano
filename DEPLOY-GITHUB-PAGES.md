# MEKANO — GitHub Pages

Le projet est un site statique : aucune étape de build n'est requise.

1. Envoyer le contenu décompressé à la racine du dépôt (ne pas envoyer uniquement le ZIP).
2. Inclure le dossier `assets/` et les trois fichiers `mekano-config.js`, `mekano-pro.js`, `mekano-pro.css`.
3. Dans GitHub : `Settings → Pages → Deploy from a branch → main → /(root)`.
4. Ouvrir `/`, `/pneus.html` et `/accessoires.html` et vérifier les images, les formulaires et la console du navigateur.
5. Installer la PWA, ouvrir les trois pages une première fois, puis tester le mode avion.

Le projet utilise des chemins relatifs (`./`) pour fonctionner également sous le sous-chemin `/mekano/` de GitHub Pages.
